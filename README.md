# Pflegeinterventionen

Interaktive HTML-Präsentation für den FaGe-Unterricht.

**Präsentation öffnen:** https://djufer1.github.io/pflegeinterventionen/

- 10 Folien mit interaktiven W-Fragen und Praxisbeispielen
- Wissenscheck mit Rückmeldungen
- Partnerauftrag mit 30-Minuten-Timer und Ergebnis-Download
- Offline nutzbar durch Herunterladen der Datei `index.html`

Navigation: Pfeiltasten. Vollbild: F. Übersicht: O.

Eingaben werden ausschliesslich lokal im jeweiligen Browser gespeichert und nicht an einen Server gesendet.

Grundlage: Dominique Jufer, «Input Pflegeinterventionen», 03.21. Quellen und Erläuterungen sind in der Präsentation enthalten.
